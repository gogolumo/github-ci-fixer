# Free versus Pro

| Capability | Free — $0 | Pro — $24.99 one-time target |
| --- | --- | --- |
| Saved text log diagnosis | Yes, complete standalone workflow | Yes |
| Offline, no paid API | Yes | Yes |
| Redacted evidence and recommendations | Yes | Yes |
| Markdown | Yes | Yes |
| Structured JSON and schema | Internal objects only; no public JSON CLI | Yes |
| Read GitHub run/jobs/commit with gh | No | Yes, explicit network action |
| Compare runs | No | Same-workflow metadata comparison |
| Group identical failures across jobs | Individual findings | Related-signature groups, cautious cause assessment |
| Java and OS-specific signatures/guides | Common command/file/access errors | Additional tested Java/macOS/Windows/Ubuntu categories |
| Workflow file inspection | Recommendations only | Simple scalar inspection at failed commit or local repository |
| Concrete patch preview | Agent-guided recommendations | One guarded Python install-step diff recipe |
| Approved local check execution | No | Snapshot/hash-bound predefined check kinds |
| Automatic edit/push/merge/deploy | No | No |

Choose Free for a useful single saved-log diagnosis. Choose Pro for recurring run-wide evidence
collection, report automation and a reviewed verification record. No diagnosis is a verified repair.
Verification is opt-in and creates no sandbox. Installed dependencies, child tools, home configuration and network inputs remain outside its captured-source checks. Pro supports one narrow diff recipe. License/purchase
terms apply; compatibility and platform test status are documented in the release report.
